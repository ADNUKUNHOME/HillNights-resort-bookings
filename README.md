# Hillnight Resort

A modern and immersive resort booking web application designed to showcase the Hillnight Resort experience while providing users with a smooth and intuitive booking interface.

The project focuses on combining a visually rich resort presentation with a functional booking experience, using modern web technologies, responsive design, and smooth animations.

## Features

- 🏨 Detailed resort overview and accommodation presentation
- 🖼️ Immersive image galleries and visual sections
- 📱 Fully responsive design across devices
- 🎨 Modern and clean UI/UX
- ✨ Smooth animations and transitions
- ⚡ Fast and optimized Next.js application
- 🧩 Type-safe development with TypeScript

## Tech Stack

### Frontend
- **Next.js**
- **React**
- **TypeScript**
- **Tailwind CSS**
- **Framer Motion**

### Development & Deployment
- **Git & GitHub**
- **Vercel**

## Getting Started

### Installation

Clone the repository:
```text
https://github.com/ADNUKUNHOME/HillNights-resort-bookings.git
```

Navigate to the project:
```text
cd hillnights-resort-bookings
```

Install dependencies:
```text
npm install
```
